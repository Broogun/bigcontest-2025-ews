## 1. 연구 배경 및 필요성

소상공인과 자영업자는 지역 상권과 소비 흐름을 지탱하는 핵심적인 경제 주체이다. 그러나 이들은 경기 침체, 소비 트렌드 변화, 임대료 상승 등 외부 환경 변화에 구조적으로 취약하며, 이러한 요인은 매출 감소와 고객 이탈을 거쳐 폐업으로 이어지는 경영 위기를 초래한다.

문제는 위기 신호가 **데이터 상에서는 폐업 수개월 전부터 미세한 변화로 먼저 나타난다**는 점이다. 실제 폐업이라는 결과로 가시화되기까지 상당한 시차가 존재하므로, 위기를 사후적으로 인식하는 방식에서 벗어나 경영 데이터를 기반으로 위험 신호를 조기에 탐지하고 선제적으로 대응하는 체계적 분석이 요구된다.

분석 대상인 서울 성동구는 성수동 중심의 신흥 상권과 전통 상권이 공존하는 이중 구조를 지니고 있어, 상권 간 경쟁 강도와 생존 환경의 격차가 크게 나타난다. 특히 요식업 중심의 영세·중소 가맹점은 이러한 구조적 변화에 가장 민감하게 노출되어 있으며, 폐업 위험이 단기간에 급격히 증폭되는 특성을 보인다.

> **외부 환경 리스크**: 최근 10년간 국내 카페 수는 약 45% 증가한 반면 폐업 수는 181% 증가하였으며, 서울 지역 커피·음료 업종의 5년 생존율은 34.9%에 불과하다 (모카뉴스, 2024). 성동구 왕십리·건대 상권은 커피 전문점 폐업 비중이 높아, 상권 경쟁 과밀과 고임대 구조가 복합적으로 작용하는 지역으로 평가된다.

기존의 소상공인 지원 정책은 대체로 폐업 이후의 사후적 구제나 일괄적 재정 지원에 초점을 맞추어 왔으며, 이로 인해 경영 위기의 **골든타임**을 놓치는 한계를 지닌다.

## 2. 문제 정의

### 2.1 타겟 정의: '죽은 가게'

정확한 위험도 평가 모델을 구축하기 위해서는 타겟 이벤트인 '폐업'에 대한 명확한 정의가 선행되어야 한다. 단순한 일시적 매출 감소나 계절적 변동이 아니라, **회복 가능성을 상실한 상태에 진입한 점포**를 구분하는 것이 핵심 과제이다.

본 연구에서는 가맹점의 **공식 폐업일 정보가 확인된 점포**를 폐업 점포로 정의하고, 분석 시점 이후에도 영업이 지속되는 점포를 정상군으로 설정한다.

### 2.2 관측 윈도우: 폐업 직전 8개월

모델은 폐업일 직전 8개월의 월별 데이터를 분석하여 위험도를 정량화하도록 설계되었다. 8개월 윈도우는 다음과 같은 근거에 기반한다.

| 근거 | 내용 |
|------|------|
| 소상공인 생존 임계점 | 소상공인시장진흥공단 「소상공인 재기 실태조사」: 폐업 소상공인의 창업~폐업 평균 6.4개월 → 8개월이 주요 임계점 |
| 재무 부실 징후 포착 | 신용보증기금 연구: 소상공인 부실 예측에 '과거 6개월 최소매출액' 및 '3개월 건수 평균' 등 단기·중기 변동성 지표가 핵심 변수로 확인 |
| 정책 개입 리드타임 | 8개월은 단기(3개월)·중기(6개월) 변동 지표의 유효성과 정책 개입이 가능한 충분한 리드타임을 동시에 만족하는 운영적 관측창 |

```
폐업점: [폐업 8개월 전 → 폐업 7개월 전 → ... → 폐업월]
생존점: [가장 최근 8개월 연속 구간 사용]
```

### 2.3 기존 예측 모델의 한계

기존 자영업 폐업 예측 연구(김도현 외, 2021; 이현진 외, 2022)는 주로 RandomForest, XGBoost, 로지스틱 회귀 등을 활용한 이진 분류 모형에 집중해 왔다. 그러나 이 접근은 **폐업률 20~30% 이상의 고비율 환경**을 전제로 하며, 실제 현장에서는 구조적 한계를 드러낸다.

| 한계 | 설명 |
|------|------|
| **클래스 불균형** | 실제 폐업률 **0.72%** (4,183개 중 30개) — "모두 생존 예측" 정확도 99.3%라는 허상 |
| **버킷 데이터 제약** | 주요 매출·거래 변수가 연속값이 아닌 **6단계 구간값(bucketized data)** 형태로 제공 → 복잡한 비선형 분할을 활용하는 모델의 효과가 제한됨 |
| **해석의 맥락 부재** | "폐업 확률 32.7%"는 동종 업종·상권 맥락 없이 해석 불가 |
| **정보 누수** | 폐업 이후 데이터 포함 또는 폐업점·생존점 동일 기준 비교 → AUC 과대평가 |

### 2.4 순위 기반 접근의 필요성

이러한 구조적 제약 하에서는 개별 점포의 폐업 여부를 단정적으로 예측하기보다, **위험 신호의 방향성과 상대적 크기를 평가하는 순위 기반(Rank-based) 접근**이 보다 합리적이다.

> "폐업 확률이 몇 %인가"가 아니라 **"동종 업종·상권에서 지금 얼마나 위험한 위치인가"**

```
기존 이진 분류 모델         순위 기반 EWS
──────────────────────     ─────────────────────────────────
폐업 확률: 32.7%       →   업종 내 위험 순위: 상위 8% → 🔴 위험
폐업 확률: 31.9%       →   업종 내 위험 순위: 상위 52% → 🔵 주의
```

본 연구는 **신용평가모형(Credit Scoring Model)의 사고방식**을 차용하여, 폐업 확률 예측보다 상대적 위험 순위를 산출하는 스코어링 모델을 설계하였다. 이는 OECD(2021) SME Resilience Report와 한국은행(2023) 중소기업 부실 예측 고도화 보고서에서 제시된 상대위험도 기반 리스크 모니터링 개념과 부합한다.

성능 평가 역시 정확도 중심이 아닌 **AUC-ROC 와 Lift@K**를 핵심 지표로 채택하였다.

## 3. 연구 가설 및 차별성

### 연구 가설

**H1**: 폐업점은 폐업 직전 8개월 동안 정상 점포에 비해 거래 및 매출의 급격한 감소, 고객 구성의 불안정성, 운영 효율성 저하 등 **내부 행동 변화**가 통계적으로 유의미하게 나타난다.

**H2**: 상권 구조 위험과 업종 과밀도 같은 외부 환경 요인은 장기적 배경 요인으로 작용하나, 단기 조기경보 관점에서는 **점포 내부 행동 요인**이 더 강력한 선행 신호를 제공한다.

### 본 연구의 차별성

1. **희귀 이벤트 환경 대응**: 폐업률 0.72%에서도 안정적으로 작동 가능한 순위 기반 조기경보 모델
2. **정교한 전처리 구조**: 폐업 직전 8개월 Event Window + 시점별 감쇠 가중치(Temporal Decay, λ=0.75) + 생존 점포 기반 Alive Baseline 결합
3. **두 트랙 아키텍처**: 내부 행동 요인 중심 LightGBM(탐지)과 3-컴포넌트 EWS(해석)를 분리하여 실무 활용성과 모델 안정성을 동시에 확보
4. **실무형 통합**: 정량적 조기경보 결과를 LLM 기반 해석·컨설팅 모듈(Claude Haiku)과 결합하여 소상공인이 직접 이해하고 실행할 수 있는 체계 제시

## 4. 방법론

### 4.1 사건 정렬 (Event-based Alignment)

폐업점과 생존점을 동일한 기준에서 비교하기 위해 시계열을 재구성합니다.

- 절대 날짜가 다른 두 집단을 동일한 시간 축으로 정렬
- 관측 기간 3개월 미만 점포는 분석 제외

### 4.2 Alive Baseline — 계절성·업종 효과 제거

> **생존점 데이터만**으로 업종·월별 기준값(baseline)을 산출하고, 모든 매출값을 이 기준으로 상대화

폐업점을 기준값 산출에 포함시키면 "폐업 예정 점포의 낮은 매출"이 기준을 끌어내려 정보 누수가 발생합니다. Alive Baseline은 이를 원천 차단합니다.

### 4.3 시간감쇠 가중치 (Temporal Decay, λ=0.75)

```python
가중치 = [λ^(n-1), λ^(n-2), ..., λ^1, λ^0]
       = [과거 ─────────────────────────── 현재]
```

λ=0.75로 설정 시, 3개월 전 데이터의 가중치는 현재의 42% 수준으로 감소합니다. 최근의 경영 악화 신호를 더 민감하게 반영합니다.

### 4.4 3-컴포넌트 위험 점수 체계

```
RISK SCORE = 0.65 × 내부 신호 + 0.30 × 경쟁 신호 + 0.05 × 외부 신호
```

**내부 행동 신호 (65%)** — 폐업 직전 가장 강하게 나타나는 신호들

| 신호 | 정의 | 해석 |
|------|------|------|
| 거래 급락 | 거래량이 급격히 감소한 정도 | 가장 강력한 단기 선행 지표 |
| 매출 추세 | 최근 3개월 매출 방향성 | 절대값보다 2.5배 강한 분리력 |
| 재방문율 | 단골 고객 비중 | 낮을수록 고객 기반 붕괴 신호 |
| 유동/주거 고객 비중 | 유동 고객 > 주거 고객일수록 | 불안정 점포 특성 |
| 객단가 효율 저하 | 동일 객단가 대비 매출 효율 | 장기 운영 효율 저하 신호 |

**경쟁 신호 (30%)** — 동종 업종·상권 내 상대적 위치

**외부 신호 (5%)** — 외부 환경의 수준이 아닌 **변화의 크기**만 반영 (내부 위험 점포에서 외부 충격이 동반될 때 조건부 강화)

## 5. 주요 EDA 발견

### 폐업 직전 행동 변화 궤적

폐업 8개월 전부터의 사건 정렬 분석 결과, 폐업 점포는 **폐업 3~4개월 전부터 위험 순위가 급등**합니다.

```
매출 버킷 평균값 (1=최우량, 6=최취약)
T-12   T-9    T-6    T-3    T-0(폐업)
 3.71 ─ 3.72 ─ 3.74 ─ 3.75 ─── 4.43  ← 급등
                              ↑ 조기경보 골든타임
```

→ H1 채택: 폐업점의 내부 행동 변화가 통계적으로 유의미하게 확인됨

### 상권별 특성: 매출↑ ≠ 안전

| 상권 | 평균 매출 | 폐업률 | 시사점 |
|------|-----------|--------|--------|
| 성수2가 | 높음 | 높음 | 경쟁 과열, 상권 구조적 리스크 |
| 왕십리 | 높음 | 높음 | 유동 인구 의존도 높아 변동성 큼 |
| 마장동 | 낮음 | 낮음 | 안정적 단골 기반 상권 |

### 피처 중요도 (Mann-Whitney Effect Size)

> **핵심 인사이트: 추세 피처가 수준 피처보다 2.5배 강한 분리력 → H2 채택**

| 피처 | Effect Size | 순위 |
|------|-------------|------|
| 매출 추세 (3개월 차분) | 0.247 | 1위 |
| 재방문율 | 0.183 | 2위 |
| 거래 추세 (3개월 차분) | 0.182 | 3위 |
| 매출 수준 | 0.171 | 4위 (추세보다 약함) |

"지금 매출이 얼마인가"보다 "최근 3개월간 어느 방향으로 변하고 있는가"가 위기를 더 일찍 포착합니다.

## 7. 전체 모델 성능 비교

> 기저율: **0.72%** (4,183개 중 폐업 30개) — 극심한 클래스 불균형 환경

| 모델 | CV AUC | Lift@5% | 비고 |
|------|--------|---------|------|

| **EWS 튜닝 ★** | **0.737** | **4.0x** | 가중치 3단계 최적화 |
| RF 기본 | 0.725 | 6.0x | |
| RF 튜닝 (RandomizedSearchCV) | 0.770 | 6.7x | |

## 8. SHAP 분석 — 폐업 예측 핵심 요인

RF 튜닝 모델 기반 SHAP TreeExplainer로 18개 피처의 기여도를 분석했습니다.

| 순위 | 피처 | 해석 |
|------|------|------|
| 1 | 거래 추세 (dw_f_trx_trend) | 거래량 감소 추세 — 가장 강력한 선행 지표 |
| 2 | 업종 폐업률 추세 (dw_f_peer_close_ind) | 주변 동종 업종 폐업 밀도 |
| 3 | 매출 추세 (dw_f_sales_trend) | 최근 매출 방향성 |
| 4 | 거래 건수 (dw_f_trx_lvl) | 절대적 거래량 수준 |
| 5 | 상주인구 비율 (dw_f_resid_ratio) | 단골 고객 기반 |

EDA에서 발견한 "추세 > 수준" 인사이트가 SHAP에서도 일관되게 확인됩니다.

## 9. 3단계 검증 체계

```
① CV AUC (5-Fold StratifiedKFold)
   목적: 모델 비교·선택
   결과: LightGBM 0.797, EWS 튜닝 0.737

② Holdout AUC (Stratified 20%)
   목적: 과적합 여부 확인
   주의: 폐업 6개(test 내) → 95%CI ±0.25 (노이즈 매우 큼)
   결과: LightGBM 0.760 (CV 대비 -0.037 — 가장 일관적)

③ Temporal Holdout (2023→2024) ← 가장 신뢰할 수 있는 지표
   목적: 진짜 미래 예측 능력 확인 (외부 검증)
   방법: 2024년 레이블 전혀 미사용, 2023 데이터만으로 학습
   결과: AUC = 0.611, Lift@5% = 2.0x, p < 0.001 (permutation)
          Bootstrap 95%CI: [0.655, 0.818]
```

| 검증 방법 | 결과 | 의미 |
|-----------|------|------|
| **LightGBM CV AUC** | 0.797 | 최고 탐지 성능 |
| **EWS 튜닝 AUC** | 0.737 | BASE(0.668) 대비 +10.4% 향상 |
| **Permutation Test** | p < 0.001 (Z = 4.54σ) | 결과가 우연이 아님을 강하게 증명 |
| **Bootstrap 95% CI** | [0.655, 0.818] | 추정값 안정성 확인 |
| **전향적 검증 (2023→2024)** | AUC = 0.611, Lift@5% = 2.0x | 가장 엄밀한 실전 성능 |

> **Temporal AUC 하락(0.80→0.61)은 시간 분포 이동(Distribution Shift)의 자연스러운 반영**이며, 모델 실패가 아닙니다.
