# 성동구 소상공인 경영위기 조기경보 시스템 (EWS)
**2025 빅콘테스트 AI데이터 분석분야** — 우리 동네 가맹점, 위기 신호를 미리 잡아라!

## 프로젝트 개요
서울 성동구 영세·중소 요식 가맹점(4,183개)의 월별 카드거래 데이터를 분석하여 경영위기 징후를 조기에 탐지하는 **순위 기반 조기경보 시스템(Rank-based EWS)** 을 구축합니다.

## 핵심 접근법
- 전통적 이진 분류 대신 **업종·상권 내 상대적 위험 순위(백분위)** 로 리스크 산출
- 시간감쇠 가중 평균(λ=0.75)으로 최근 신호를 강조한 스냅샷 생성
- 내부(매출·거래) / 경쟁(상권 내 위치) / 외부(폐업 밀도) 3개 컴포넌트 합산

## 모델 성능
| 검증 방법 | 결과 |
|-----------|------|
| TUNED AUC | 0.737 |
| Bootstrap 95% CI | [0.653, 0.818] |
| Permutation test | p < 0.001 (Z = 4.54σ) |
| 전향적 검증 (2023→2024) | AUC = 0.611, Lift@5% = 2.0x |

## 빠른 시작

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 데이터 준비
`data/` 폴더에 아래 파일을 위치시킵니다 (대회 제공 원본):
- `big_data_set1_f.csv` — 점포 마스터
- `big_data_set2_f.csv` — 월별 매출
- `big_data_set3_f.csv` — 월별 고객

### 3. 노트북 순서대로 실행
```
notebooks/01 → 02 → 03 → 04 → 05 → 06
```
각 노트북은 이전 노트북의 `outputs/` 산출물을 이어받습니다.

### 4. 대시보드 실행
```bash
cd app
streamlit run app_ews.py
```
