## 배경

서울 성동구의 영세·중소 요식 가맹점은 우리 경제의 근간을 이루지만, 급변하는 소비 환경 속에서 폐업 위기에 쉽게 노출됩니다. 문제는 **위기가 찾아왔을 때 대부분의 자영업자가 이미 손쓰기 어려운 단계**라는 점입니다.

폐업 직전 수개월간 카드거래 데이터에는 이미 경영 악화의 선행 신호가 축적됩니다.

```
폐업 8개월 전   →   폐업 3개월 전   →   폐업
거래 건수 완만히 감소    급격히 감소       매출 붕괴
재방문율 하락 시작       단골 이탈 가속
업종 내 순위 하락        상권 내 하위권 고착
```

그러나 이 신호를 **개인의 경험만으로 조기에 포착하는 것은 불가능**합니다. 데이터가 필요합니다.

## 문제 정의

### 기존 접근법의 한계

| 한계 | 설명 |
|------|------|
| **이진 분류의 함정** | 폐업(1) vs 생존(0)으로 단순화 → 전체의 약 3%에 불과한 폐업 사례로는 극심한 클래스 불균형 발생. "폐업 확률 32.7%"는 맥락 없이 해석 불가 |
| **정적 특성 의존** | 업종·위치 등 고정 속성 위주 → 시간에 따라 점진적으로 악화되는 경영 신호를 포착하지 못함 |
| **정보 누수 (Data Leakage)** | 폐업 이후 데이터를 훈련에 포함하거나, 폐업점과 생존점을 같은 기준으로 비교 → AUC 과대평가. 실제 배포 환경에서 성능 급락 |
| **절대값 해석의 한계** | 매출 200만 원이 위험한지 안전한지는 업종·상권 맥락 없이 판단 불가 |

### 본 연구의 접근: 순위 기반 조기경보 (Rank-based EWS)

> "폐업 확률이 몇 %인가"가 아니라 **"동종 업종·상권에서 지금 얼마나 위험한 위치인가"**

```
기존 이진 분류 모델         순위 기반 EWS
──────────────────────     ─────────────────────────────────
폐업 확률: 32.7%       →   업종 내 위험 순위: 상위 8% → 🔴 위험
폐업 확률: 31.9%       →   업종 내 위험 순위: 상위 52% → 🔵 주의
```

동일 수치도 **동종 대비 맥락** 속에서 해석해야 의미 있습니다.

## 방법론

### 1. 사건 정렬 (Event-based Alignment)

폐업점과 생존점을 동일한 기준에서 비교하기 위해 시계열을 재구성합니다.

```
폐업점: [폐업 8개월 전 → 폐업 7개월 전 → ... → 폐업월]
생존점: [가장 최근 8개월 연속 구간 사용]
```

- 절대 날짜가 다른 두 집단을 동일한 시간 축으로 정렬
- 관측 기간 3개월 미만 점포는 분석 제외

### 2. Alive Baseline — 계절성·업종 효과 제거

> 계절 효과 제거: **생존점 데이터만**으로 업종·월별 기준값(baseline)을 산출하고, 모든 매출값을 이 기준으로 상대화

폐업점을 기준값 산출에 포함시키면 "폐업 예정 점포의 낮은 매출"이 기준을 끌어내려 정보 누수가 발생합니다. Alive Baseline은 이를 원천 차단합니다.

### 3. 시간감쇠 가중치 (Temporal Decay, λ=0.75)

> 최근 신호일수록 더 중요하다

```python
가중치 = [λ^(n-1), λ^(n-2), ..., λ^1, λ^0]
       = [과거 ─────────────────────────── 현재]
```

λ=0.75로 설정 시, 3개월 전 데이터의 가중치는 현재의 42% 수준으로 감소합니다. 최근의 경영 악화 신호를 더 민감하게 반영합니다.

### 4. 3-컴포넌트 위험 점수 체계

```
RISK SCORE = 0.65 × 내부 신호 + 0.30 × 경쟁 신호 + 0.05 × 외부 신호
```

**내부 행동 신호 (65%)** — 폐업 직전 가장 강하게 나타나는 신호들

| 신호 | 정의 | 해석 |
|------|------|------|
| 거래 급락 | 거래량이 급격히 감소한 정도 | 가장 강력한 단기 선행 지표 |
| 매출 추세 | 최근 3개월 매출 방향성 | 절대값보다 2.5배 강한 분리력 |
| 재방문율 | 단골 고객 비중 | 낮을수록 고객 기반 붕괴 신호 |
| 유동/주거 고객 비중 | 유동 고객 > 주거 고객일수록 | 불안정 점포 특성 |
| 객단가 효율 저하 | 동일 객단가 대비 매출 효율 | 장기 운영 효율 저하 신호 |

**경쟁 신호 (30%)** — 동종 업종·상권 내 상대적 위치

**외부 신호 (5%)** — g_ext_index: 외부 환경의 **수준이 아닌 변화의 크기**만 반영

> **외부 요인 설계 원칙**: 입지·업종에 따라 외부 레벨 차이가 크므로 직접 합산하면 순위 안정성(Ranking Stability)이 훼손됩니다. 따라서 외부 환경은 "내부 위험이 높은 점포에서 외부 충격이 동반되는 경우 위험 신호를 조건부 강화"하는 Booster 레이어로만 활용합니다.

## 주요 EDA 발견

### 폐업 직전 행동 변화 궤적

폐업 8개월 전부터의 사건 정렬 분석 결과, 폐업 점포는 **폐업 3~4개월 전부터 위험 순위가 급등**합니다.

```
매출 버킷 평균값 (1=최우량, 6=최취약)
T-12   T-9    T-6    T-3    T-0(폐업)
 3.71 ─ 3.72 ─ 3.74 ─ 3.75 ─── 4.43  ← 급등
                              ↑ 조기경보 골든타임
```

### 상권별 특성: 매출↑ ≠ 안전

흥미롭게도 **높은 매출이 낮은 폐업률을 보장하지 않습니다.**

| 상권 | 평균 매출 | 폐업률 | 시사점 |
|------|-----------|--------|--------|
| 성수2가 | 높음 | 높음 | 경쟁 과열, 상권 구조적 리스크 |
| 왕십리 | 높음 | 높음 | 유동 인구 의존도 높아 변동성 큼 |
| 마장동 | 낮음 | 낮음 | 안정적 단골 기반 상권 |

> 폐업은 단순한 매출 규모의 문제가 아니라 **상권 구조적 리스크**와 밀접하게 연관됩니다.

### 업종별 폐업률

- 🔴 **고위험 업종**: 식품제조, 양식, 패스트푸드 → 구조적으로 높은 폐업률
- 🟢 **안정 업종**: 한식뷔페 → 비교적 안정적인 생존 패턴

특정 업종이 특정 상권에 과도하게 집중될수록 폐업률 상승 경향 확인.

### 피처 중요도 (Mann-Whitney Effect Size)

> **핵심 인사이트: 추세 피처가 수준 피처보다 2.5배 강한 분리력**

| 피처 | Effect Size | 순위 |
|------|-------------|------|
| 매출 추세 (3개월 차분) | 0.247 | 1위 |
| 재방문율 | 0.183 | 2위 |
| 거래 추세 (3개월 차분) | 0.182 | 3위 |
| 매출 수준 | 0.171 | 4위 (추세보다 약함) |

"지금 매출이 얼마인가"보다 "최근 3개월간 어느 방향으로 변하고 있는가"가 위기를 더 일찍 포착합니다.

## 모델 성능 및 통계 검증

단순 AUC 보고에 그치지 않고 **3가지 독립 검증**으로 타당성을 확인했습니다.

| 검증 방법 | 결과 | 의미 |
|-----------|------|------|
| **TUNED AUC** | 0.737 | BASE(0.668) 대비 +10.4% 향상 |
| **Permutation Test** | p < 0.001 (Z = 4.54σ) | 결과가 우연이 아님을 강하게 증명 |
| **Bootstrap 95% CI** | [0.653, 0.818] | 추정값 안정성 확인 (하한이 0.5 초과) |
| **전향적 검증 (2023→2024)** | AUC = 0.611, Lift@5% = 2.0x | 2023 데이터만으로 2024 폐업 예측 |

> **전향적 검증**: 2024년 폐업 레이블을 전혀 사용하지 않고 2023년 데이터만으로 15개 폐업 점포를 예측. 가장 엄밀한 방법으로 실제 조기경보 가능성을 검증.

## 활용 시나리오

본 시스템이 제공하는 핵심 가치는 **폐업 약 8개월 이전의 선행 신호 포착**입니다. 이 골든타임 안에 개입하면 사후 지원보다 훨씬 높은 예방 효과를 기대할 수 있습니다.

**지자체·공공기관**
한정 예산을 무작위 배분하지 않고, 위험 점포 순위 기반으로 우선 지원 대상을 선별해 맞춤형 재정·컨설팅 프로그램 운영.

**금융기관**
대출 가맹점 리스크를 조기에 관리하고, 폐업 우려 점포에 상환 유예나 맞춤 금융상품을 제안해 부실 채권 발생을 사전에 완화.

**민간 플랫폼 (배달앱·POS 사업자)**
판매자 위험 관리 시스템에 EWS를 통합해 건전한 판매자 생태계 유지.
